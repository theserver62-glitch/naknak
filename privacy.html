낙낙 개인정보처리방침

시행일 2026년 10월 17일 · 적용 대상: 낙낙 - 취미찾기 웹사이트, Android 앱, 토스 미니앱

1. 수집하는 개인정보

낙낙은 회원가입이나 로그인이 없고, 이름·연락처·위치 같은 개인정보를 수집하지 않아요. 운영자가 따로 두는 서버도 없어서, 앱에서 고른 답이 운영자에게 전송되지 않아요.

2. 이용자 기기에만 저장되는 정보

앱을 편하게 쓰도록 아래 내용을 이용자 기기의 브라우저 저장소에만 저장해요. 운영자는 이 정보를 볼 수 없어요.

  • 마지막으로 고른 답 (다시 열었을 때 결과를 보여 주기 위해)
  • ‘해보고 싶어요’로 찜한 취미, 첫날 체크리스트
  • 질문을 시작·완료한 횟수, 상세를 본 취미 같은 이 기기 안의 숫자 기록

브라우저의 사이트 데이터 삭제나 앱 삭제로 언제든 지울 수 있어요.

3. 이용자가 직접 보내는 의견

결과 화면의 ‘피드백 복사’를 누르면 고른 답 번호, 추천 결과, 2번의 숫자 기록이 담긴 글이 복사돼요. 이 글은 이용자가 직접 붙여 넣어 보낼 때만 전달되고, 앱이 자동으로 보내지 않아요. 이름 같은 개인정보는 담기지 않아요.

4. 외부 서비스

  • GitHub Pages: 웹사이트를 제공하는 호스팅이에요. 접속 시 GitHub가 보안을 위해 IP 주소 같은 접속 기록을 처리할 수 있어요 (GitHub 개인정보 처리방침).
  • jsDelivr: 본문 글꼴(Pretendard)을 불러올 때 jsDelivr 서버에 접속해요 (jsDelivr 개인정보처리방침).
  • Google Fonts: 제목 글꼴(Bagel Fat One)을 불러올 때 Google 서버에 접속해요 (Google 개인정보처리방침).
  • 쿠팡 파트너스: 준비물 옆 ‘쿠팡에서 보기 (광고)’ 링크는 쿠팡 파트너스 링크예요. 누르면 쿠팡으로 이동하고, 쿠팡이 구매 실적을 확인하려고 쿠키 등을 쓸 수 있어요. 낙낙은 이 정보를 받지 않아요. 이를 통해 구매가 이뤄지면 운영자가 일정액의 수수료를 받아요 (쿠팡 개인정보처리방침).
  • 취미 상세의 ‘바로 가기’ 링크는 다른 사이트로 이동해요. 이동한 사이트에서는 그 사이트의 방침이 적용돼요.

위 쿠팡 링크 말고는 광고, 분석 도구, 추적 쿠키를 쓰지 않아요.

5. 아동의 개인정보

낙낙은 누구의 개인정보도 수집하지 않으므로 만 14세 미만 아동의 개인정보도 수집하지 않아요.

6. 방침 변경과 문의

수집 방식이 바뀌면 이 페이지를 먼저 고치고 시행일을 바꿔요. 문의는 GitHub 문의 게시판에 남겨 주세요.
